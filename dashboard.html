What the frames can and cannot do

  • They emulate the screen width and height, so CSS breakpoints and layout.
  • They do not change the User-Agent sent to the server, the pixel density or touch events. Use the DevTools device mode for those.
  • To frame any site, the bench removes the X-Frame-Options and Content-Security-Policy headers in its frames. You will therefore not see CSP errors. This applies only to this tab.
  • The frames run as content embedded in another site. The server gets all cookies, so logins work, but the page's JavaScript only sees SameSite=None cookies and cannot set new ones. A cookie banner may therefore keep coming back.
  • Service workers are disabled in the frames so the page can always be reloaded.
  • Mobile and tablet have overlay scrollbars like a phone, desktop has classic ones.
  • All three frames load at once and share the network. Performance → Measure again loads a single frame for more exact numbers.
